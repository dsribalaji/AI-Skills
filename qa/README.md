# Effex.dev Toolkit Hub - Quality Assurance (QA)

Welcome to the **Quality Assurance (QA)** toolkit directory for the Effex.dev project.

This folder contains the templates, guidelines, and folder structure necessary to manage the entire QA lifecycle, from test planning to defect management and automation. It is designed to be used by QA professionals and AI agents to ensure a structured and traceable approach to software quality.

## Structure Overview

*   **`01_test-planning/`**: Strategy and overarching test plans.
*   **`02_test-design/`**: Test scenarios and detailed cases.
*   **`03_test-execution/`**: Test runs and execution results.
*   **`04_defect-management/`**: Bug reports and triage documentation.
*   **`05_test-automation/`**: Automation strategies and script references.
*   **`.copilot/`**: Agent skills and configurations specific to the QA role.

## Getting Started

1.  Review `PROJECT_FOLDER_STRUCTURE.md` to understand the directory layout and naming conventions.
2.  Review `AGENTS.md` for guidelines on how AI agents should interact with this QA toolkit.
3.  Begin working in the appropriate phase folder (e.g., start with `01_test-planning/` for a new project).

Remember to maintain traceability by linking test artifacts back to the original requirements and user stories (often found in the `ba/` directory).
