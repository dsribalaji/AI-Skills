# QA Agent Skill: Defect Management

## Intent
Streamline bug reporting and assist with defect triage.

## Capabilities
- Generating comprehensive bug report templates (steps to reproduce, expected vs. actual, attachments).
- Structuring defect triage logs.
- Assisting with bug prioritization based on impact and severity.

## Usage
Triggered when working in the `qa/04_defect-management/` directory.

## Best Practices
- Ensure bugs trace back to the failed test run or specific requirement.
- Use clear, objective language when describing defects.
