# QA Agent Skill: Test Planning

## Intent
Guide the creation of comprehensive test strategies and test plans.

## Capabilities
- Assisting with defining test scope, approach, environments, and tools.
- Generating draft test plans based on project requirements (e.g., BRDs).
- Identifying potential risks and suggesting mitigation strategies.

## Usage
Triggered when working in the `qa/01_test-planning/` directory.

## Best Practices
- Ensure all test plans are linked to stakeholder requirements.
- Maintain a focus on measurable objectives and clear entry/exit criteria.
