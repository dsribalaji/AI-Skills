# Effex.dev Toolkit Hub

Welcome to the skill and toolkit repository for the **Effex.dev** project (`dsribalaji/effex.dev`).

This repository serves as a centralized hub containing the workflows, templates, and agent tools for different project roles. Currently, we have established the structure and tools for the **Business Analyst (BA)** role. In the future, this repo will expand to include directories and tools for other roles (e.g., developers, QA, DevOps, designers, etc.).

## Repository Structure

The root directory is organized by roles.

### Roles

*   [`ba/`](ba/) - **Business Analyst**: Contains the tools, agent prompts, skills, and the full multi-phase folder structure necessary for stakeholder discovery, elicitation, requirement gathering, use cases, and non-functional requirements.

### Adding New Roles

As the project scales, new roles will have their own top-level directories in this repository. Each role's directory should be self-contained and provide the templates, guidelines, and skills that AI agents or team members need to fulfill that specific role's workflows.
